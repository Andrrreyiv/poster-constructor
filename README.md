# Конструктор постеров на металле

Прототип конструктора для jetronsport.ru: покупатель выбирает размер металлической
пластины, кладёт на неё свою картинку или принт из библиотеки и при желании добавляет раму.

**Демо:** https://andrrreyiv.github.io/poster-constructor/

## Что умеет прототип

- шесть размеров пластин, цена привязана к размеру;
- книжная и альбомная ориентация;
- библиотека принтов по тематикам плюс загрузка своего файла с перетаскиванием;
- просмотр картинки крупно перед выбором;
- три вида рамы (белая, чёрная, под дерево) — рама надевается на пластину снаружи,
  картинка под ней не обрезается;
- проверка разрешения: конструктор предупреждает, если картинки не хватает на выбранную
  пластину, и называет нужный размер в точках;
- скачивание макета в пропорциях пластины.

## Что в прототипе условное

Размеры пластин, цены и пороги качества — временные значения, помеченные в
`src/config/poster-config.json` полями `_note`. Они заменяются настоящим прайсом
без правки кода. Библиотека принтов сейчас на заглушках.

Приём заказа в прототипе не работает: кнопка «Заказать» показывает состав, но никуда
его не отправляет. Корзина и касса — следующий этап.

## Как запустить локально

Сборки нет, это vanilla JS + ESM. Нужен любой статический сервер:

```bash
npx serve -p 8782 .
```
